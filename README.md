# MIMBA GRAPHICS — Online Portfolio

This is a ready-to-publish static portfolio website for Aghaindum Briyan Endum / MIMBA GRAPHICS.

## Publish with GitHub Pages
1. Create a free GitHub account at https://github.com/.
2. Create a new repository named `mimbagraphics.github.io` (Public).
3. Upload **everything inside this folder** to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Your site should become available at `https://mimbagraphics.github.io/` after GitHub finishes publishing.

## Important
- Keep the `assets` folder and its subfolders in place.
- The site uses the MIMBA GRAPHICS black/green/yellow/white identity.
- The CV and full PDF portfolio are included in `assets/docs/`.
- Replace or add project images in `assets/designs/` only if you want to expand the portfolio.
